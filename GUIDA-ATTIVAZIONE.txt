==========================================================
PROXIMA — ATTIVARE IL PANNELLO /admin E IL CONTATORE VISITE
==========================================================

Questo pacchetto aggiunge:
- Eventi e classifiche gestibili da un pannello (Decap CMS) su associazioneproxima.com/admin
- Contatore visite per pagina (GoatCounter)

----------------------------------------------------------
PARTE 0 — CARICARE I FILE SU GITHUB
----------------------------------------------------------
1. Estrai lo zip.
2. Su github.com/associazioneproxima/proxima-sito -> Add file -> Upload files.
3. Trascina TUTTO il contenuto (file + cartelle: admin, data, css, img, documenti).
   Sovrascrivi quelli esistenti quando chiede.
4. Commit changes. Netlify ripubblica da solo.

NB: ora gli eventi NON stanno piu' scritti nelle pagine, ma nei file dentro la cartella "data".
Le pagine li leggono da li'. Non modificare gli HTML a mano per gli eventi: userai il pannello.

----------------------------------------------------------
PARTE 1 — ATTIVARE IL PANNELLO /admin (una volta sola)
----------------------------------------------------------
Il pannello salva le modifiche scrivendo su GitHub. Per autorizzarlo serve attivare
due cose gratuite su Netlify: Identity (login) e Git Gateway (permesso di scrittura).

A) IDENTITY
   1. Netlify -> tuo sito -> scheda "Integrations" o "Identity".
      (Su alcuni account: Site configuration -> Identity.)
   2. Clicca "Enable Identity".
   3. In Identity -> Registration: imposta "Invite only"
      (cosi' solo chi inviti tu puo' accedere al pannello).

B) GIT GATEWAY
   1. Sempre in Identity -> scorri a "Services" -> "Git Gateway" -> Enable.
      (Collega Netlify al repo per poter salvare le modifiche.)

C) INVITA TE STESSO COME UTENTE
   1. Identity -> Invite users -> inserisci la tua email -> invia.
   2. Ti arriva una mail: clicca il link e imposta una password.
      (Se il link apre una pagina strana, aggiungi /admin all'indirizzo del sito.)

D) PROVA
   1. Vai su  https://associazioneproxima.com/admin
   2. Fai login con email+password.
   3. Vedrai due sezioni: "Eventi" e "Summer League". Prova a modificare e salvare:
      dopo il salvataggio Netlify ripubblica e in ~1 minuto vedi la modifica online.

GESTIONE EVENTI dal pannello:
- Aggiungere: Eventi -> Elenco eventi -> "Add Evento" -> compila -> Publish.
- Stato evento: campo "Stato" (Iscrizioni aperte / In corso / In programma / Archivio).
  Mettendo "Archivio" l'evento sparisce dai prossimi e compare in "Eventi passati".
- Foto/locandina: campo "Locandina" -> carica l'immagine (va da sola in img/eventi).
- Tema colore: Arancione (Gorgo Jam) / Blu (Summer League) / Viola / Neutro.
- Lo "slug" e' l'identificativo nell'indirizzo (es. gorgo-jam-2026): senza spazi.

SUMMER LEAGUE dal pannello:
- Sezione "Summer League": modifichi gironi, squadre (G/V/Pt) e prossime partite.
  L'ordine delle squadre nella lista = ordine in classifica.

----------------------------------------------------------
PARTE 2 — CONTATORE VISITE (GoatCounter)
----------------------------------------------------------
1. Vai su https://www.goatcounter.com -> crea un account gratuito.
2. Scegli un "code" per il sito, es. "proxima": avrai proxima.goatcounter.com
3. Nei file del sito, sostituisci la parola CODICE con il tuo code.
   Si trova in fondo a OGNI pagina .html, in questa riga:
     <script data-goatcounter="https://CODICE.goatcounter.com/count" ...>
   (Cerca "CODICE" e sostituisci con "proxima". Sono 7 file.)
   Suggerimento: posso rigenerarteli io gia' col codice giusto se mi dici quale hai scelto.
4. Ricarica i file su GitHub. Le statistiche le vedrai su proxima.goatcounter.com.

----------------------------------------------------------
NOTE
----------------------------------------------------------
- Il pannello funziona solo ONLINE (su associazioneproxima.com/admin), non aprendo i file in locale.
- I JSON in "data" sono leggibili/curabili anche a mano, ma il modo comodo e' il pannello.
- Foto eventi -> caricale dal pannello. Foto archivio/team -> per ora restano da inserire
  negli HTML; se vuoi gestirle anche quelle dal pannello, si puo' aggiungere (chiedimelo).
